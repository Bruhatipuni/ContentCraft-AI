# ContentCraft AI 🚀
### Intelligent AI Content Studio for Brands & Creators

**BFWAI/HACK 26 · Problem Statement 02 (PS 02)**

---

## 📖 Overview

Creators and modern brands waste **14+ hours every week** manually repurposing content, adjusting aspect ratios, maintaining disjointed brand guidelines, and formatting posts for disparate algorithms.

**ContentCraft AI** solves this with a unified, agentic AI Content Studio that transforms a single brief, article, or video transcript into a complete suite of platform-ready social copy, high-res visual cards, interactive short-form video storyboards, regional Indic translations, and synchronized publishing schedules.

---

## 🌟 12 Core Features

1. **AI Content Repurposer (5-in-1)** ⭐: Upload one blog, transcript, or topic and generate tailored copy for LinkedIn, Instagram (with 20+ hashtags), X threads, Reels scripts, and Email newsletters simultaneously.
2. **AI Visual & Ad Creative Studio** ⭐: Multi-aspect ratio design engine (**1:1**, **4:5**, **16:9**, **9:16**) with theme presets, custom typography, brand color palettes, and direct **high-resolution PNG export** via HTML5 Canvas.
3. **AI Video / Reel Generator** ⭐: Converts an idea into a 4-scene video storyboard with timing cues, B-roll recommendations, and an **interactive 9:16 vertical smartphone player** simulating live transitions and subtitles.
4. **AI Voiceover Generator**: Browser-native Web Speech API audio synthesizer with 4 distinct tone personas (*Viral Creator, Executive Leader, Storyteller, Rapid Hook*), vocal pitch/speed modulation, and an animated live waveform visualizer.
5. **Platform Format Adapter**: Side-by-side native feed simulation for **LinkedIn**, **Instagram**, **X (Twitter)**, and **YouTube Shorts** with character counters, truncated view toggles, and engagement bars.
6. **Trend & Hashtag Intelligence**: Real-time viral momentum radar (+310% surge signals), curated hashtag clouds across tech, consumer, and creator niches, and 5 A/B-tested viral hook formulas.
7. **Brand Asset Library**: Centralized multi-brand guidelines manager. Store brand voices, hex palettes with live color pickers, target audiences, approved keywords, forbidden buzzwords, and stylistic sample posts.
8. **AI Content Score & Diagnostic Optimizer**: Measurable 0-100 copy quality meter assessing **Hook Momentum**, **Readability & Whitespace**, **CTA Strength**, **Brand Alignment**, and **Platform Fit**, featuring 1-click AI optimization.
9. **One-Click Variations (A/B Testing)**: Generates 6 psychological marketing angles (*Curiosity Gap, Problem-Agitate-Solve, Contrarian, Personal Story, Data & Numbers, Urgency/FOMO*) from a single thesis.
10. **Content Calendar & Auto-Scheduling**: Visual publishing pipeline with status tracking (*Draft ➔ In Review ➔ Approved ➔ Scheduled*), time slot optimization, and JSON calendar export.
11. **AI Feedback Loop & Performance Simulator**: Monte Carlo engagement estimator predicting impressions, bookmark save rates, and share multipliers. Includes a **Dynamic AI Prompt Memory** that injects user-taught rules into all future studio generations.
12. **Multilingual Indic Studio**: Localizes campaigns across **English, Hindi (हिन्दी), Hinglish, Telugu (తెలుగు), Tamil (தமிழ்), and Marathi (मराठी)** while preserving colloquial nuances, punchlines, and brand voice. Includes live audio pronunciation.

## ⚡ The All-in-One 1-Click Campaign Studio ("Easy Mode")

For high-speed workflows, the **1-Click Campaign Studio** allows creators to pick a template or enter an idea and immediately generate:
- Social Copy (LinkedIn, Instagram, X)
- Visual Ad Creative
- 9:16 Reel Storyboard
- Indic Regional Nuances (Hindi, Hinglish, Telugu, Tamil)
- **1-Click "Schedule Entire Campaign (4 Posts)"** directly into the publishing queue.

## 🎨 Dual Theme System

- 🌞 **Clean Daylight Pro (Light Mode)**: High-contrast slate typography (`#0f172a`), clean borders (`#e2e8f0`), and vibrant accents tailored for extended daytime writing sessions.
- 🌙 **Midnight Studio (Dark Mode)**: Deep obsidian (`#09090c`) with glowing accent rings and subtle glassmorphic panels.
- Toggle between modes instantly with the sun/moon button in the top navigation bar.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite 6
- **Styling**: Tailwind CSS 3.4, Custom CSS Variables, Glassmorphism
- **Icons & Visuals**: Lucide React, HTML5 Canvas Rendering, Canvas Confetti
- **Audio**: Web Speech API Synthesizer
- **AI Engine**: Google Gemini 1.5 Flash API + Intelligent Offline Fallback Intelligence
- **Persistence**: LocalStorage with schema versioning

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Bruhatipuni/ContentCraft-AI.git

# Navigate into the project directory
cd ContentCraft-AI

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Building for Production

```bash
npm run build
```
